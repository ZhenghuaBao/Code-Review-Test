# Code-Review-Test

A scratch repository for exercising the OrcaCode Review GitHub Action end to end.

The workflow lives in `.github/workflows/orcarouter-code-review.yml`. It runs on
every push to an open pull request, and on demand when a maintainer comments
`@orcacode-review` on one.

Nothing here is a real project. Changes are made only to give the reviewer
something to look at.
